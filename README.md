# Crappybara 🐾

A 2D virtual pet and idle collector game built with Godot Engine, inspired by KleptoCats.
Raise your capybara, collect rare skins through a gacha system, and send them into battle.

## Features

- **Virtual Pet System** — feed, play, and take care of your capybara
- **Gacha Skin System** — collect skins with Genshin Impact-style rarity and drop rates
- **Battle Mode** — grind gold and XP through combat encounters
- **Idle Mechanics** — progress continues even when you're away
- **Cross-platform** — supports desktop and web (itch.io) export

## Built With

- [Godot Engine](https://godotengine.org/) (Compatibility renderer for web support)
- GDScript
